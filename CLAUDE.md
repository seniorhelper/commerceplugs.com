# Working conventions — commerceplugs.com

Standing decisions for this project. Read this before changing anything.

## Owner preferences (these are settled — do not re-ask)

- **Forms use FormSubmit, posting to `info@eyetoad.com`**, with a honeypot field
  and the scrambled alias endpoint so the address never sits in published HTML.
  Config lives in `data/site.json` under `form`. Never propose Formspree,
  Netlify Forms or a new provider.
- **Push straight to `main`.** No feature branch, no pull request, no asking the
  owner to merge. The site deploys from `main` via GitHub Pages.
- **Never ship placeholder data.** No invented products, estimated prices, or
  stock levels that were not checked. An unconfirmed field is `null` and renders
  as "Not verified". A store with no connected feed publishes no prices at all.
- **No brand names in site copy** unless that brand is listed in the catalog.
  Crawler user-agent strings in `robots.txt` are functional identifiers and stay.
- **Publisher is Eye To Ad Media** (`https://www.eyetoad.com`).

## Brand

Orange leads, violet supports, and they never appear in the same element —
orange marks what you act on, violet marks what has been counted or verified.

| Token | Value | Use |
|---|---|---|
| `--brand` | `#F15A22` | the plug mark, large fills. **Fails contrast for small text.** |
| `--brand-ink` | `#C2410C` | buttons with white text, and every text link |
| `--accent` | `#6E3BFF` | figures, counts, verified state |
| `--accent-ink` | `#5A21D6` | the same, as small text |
| `--ink` | `#0E0E11` | body text |

Type: **Bricolage Grotesque** for display, **Outfit** for everything else, both
self-hosted in `assets/fonts/`. 10px radius, no shadows. The page is light: white
masthead, light colophon, one dark band at the close.

The mark is a **plug** — body and two prongs. Not an arrow, not a CP monogram.
It is generated by `tools/make_assets.py`, which also writes the 52 Open Graph
cards. Prongs thicken below 48px or they stop reading.

## Build

```
python3 build.py                   # writes the whole site from data/*.json
python3 tools/make_assets.py       # icons, favicons, OG cards (after a data change)
python3 make_preview.py            # relative-path copy for hosting under a sub-path
```

No dependencies, no bundler. The output is committed — GitHub Pages serves it
from the repo root.

## Non-negotiables in the markup

- **Server-rendered.** AI crawlers do not run JavaScript. Every fact must be in
  the first HTTP response. `assets/app.js` only adds search, sorting and the
  plates/list switch for human visitors; nothing depends on it.
- **WCAG AA in both colour schemes.** Audit after any palette or component
  change. The recurring trap: an element carrying white text on `var(--ink)`
  inverts in dark mode and loses its ground — pin those backgrounds to a fixed
  value.

## Data

| File | Holds |
|---|---|
| `data/site.json` | brand, domain, price, publisher, form config |
| `data/categories.json` | the 16 editorial categories |
| `data/stores.json` | one record per listed store |
| `data/products.json` | listings, only from stores with a connected feed |
| `data/journal.json` | articles; a `data_post` computes its figures at build time |

Adding a store: read its public catalog (Shopify `/products.json`, WooCommerce
Store API, or sitemap + JSON-LD), spread the selection across product types so
one type does not crowd out the rest, and verify shipping, currency and returns
from the store's own policy pages before filling those fields.

## Planned, not yet built

Accounts, billing and nightly catalog re-scans go on the owner's GoDaddy
reseller VPS at `app.commerceplugs.com`, with Supabase for auth. The static
index stays on the CDN. Do not build these until the owner says the first sale
has landed.
